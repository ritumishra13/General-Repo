# General Repo

## Prerequisites

This project uses [uv](https://docs.astral.sh/uv/) to manage Python tooling used by local scripts.

### Installing uv

**macOS / Linux:**
```bash
curl -LsSf https://astral.sh/uv/install.sh | sh
```

**Windows (PowerShell):**
```powershell
irm https://astral.sh/uv/install.ps1 | iex
```
